Privacy Policy

Type Again on Web

Updated 1 October 2026

No Data Collected

Type Again has no back end and requires no account. Your text and settings are stored in your browser and stay on your device. When you import files, Type Again reads them directly from the file system; we never receive a copy. Exporting your text works the same way in reverse — your browser downloads the file straight to your device; we do not receive a copy either. The site is hosted on Cloudflare Pages, which, like any web host, handles standard request information such as IP addresses to deliver the pages.

No Third-Party Sharing

Type Again does not use any analytics tool, advertising network or third-party SDK. We do not share your information with anyone, because we do not collect any in the first place. The site loads open-source code libraries from public content delivery networks (esm.sh and jsDelivr) to power language detection — they never see anything beyond the standard technical request info any web request involves. Dictation and Autopilot use your browser's text-to-speech. Some browsers may bundle their own network-based voices — separate from your operating system's own on-device voices — that send text to the browser vendor's servers to be spoken aloud.

Already All Yours

Since Type Again does not collect personal data or request consent for such collection, there is no server-side data to retain or delete, and no consent to revoke — your device already holds everything, under your control.
